**27 / Q10 source correction:** The original audit title said “Mobile tab swipe gestures.” In the actual shipped build, HTML `Sc` calls `OL`, and `OL` tries only the two open inventory handlers (`Tv`/`sv`). It does **not** call the tab switcher `gk`. That switcher is used by keyboard/wheel paths. This checkpoint therefore matches active inventory browsing and phone-panel closing, rather than inventing a touch tab-switch path.

The source horizontal threshold is strictly more than100px in under300ms; downward close is strictly more than100px with duration over100ms and under400ms. `mobile-gestures.js` executes those classifications, browsing the next/previous visible CE grid tile and opening its existing details without equipping. This preserves the user's CE grid choice instead of substituting the source carousel. The downward close gesture belongs to the panel header in CE so its scrollable content remains native. Mining/control/drag origins, other blocking dialogs, multitouch, cancellation, blur and resize are guarded. Compatibility clicks and native image dragging are suppressed only for recognized mobile inventory gestures. Desktop pointer navigation remains unchanged; no new gesture setting is needed.
