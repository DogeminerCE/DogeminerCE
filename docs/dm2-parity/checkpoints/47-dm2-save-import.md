# Checkpoint 47: Dogeminer 2 save conversion

Open `http://localhost:8011/play/?parityTest=checkpoint-47` and press **Ctrl+\**. Four previews provide first-timeline, protected/history, UTF16/backup, and invalid-file examples. The first three open the actual import review: Cancel retains the 500-coin CE fixture; Confirm replaces it with the reviewed source progress.

Settings → **Import CE / DM2 Save** accepts CE JSON and DM2 `.doge` files encoded with the original LZ-String Base64 or UTF16 codec. Plain/URI JSON is accepted too. Conversion is deterministic: use stored rolls, equipped index, helper ownership/tier/name indices, adapted positions, known/unlocked/visited planets, found upgrades, clues, field stacks, source Mystery Box cycle, story income and per-timeline earnings/time/choices. Source Johnny maps to the retained CE Altar. Shielded, seasonal, D.I.A., Patron and Super Fortunes retain their stats/protection. Unknown item IDs retain stats and a placeholder; unsupported helpers/planets and malformed values reject the draft rather than dropping progress.

The review shows counts and relevant limitations before replacement. Original import text, the previous CE snapshot, primary save and rolling backup commit atomically. Failure restores the previous state and autosave status. Import receipts survive reload; full reset clears the receipt while originals remain available. Import starts at the saved snapshot without retroactive offline credit. Source automatic layout has no saved dimensions, so its helper coordinates use the desktop profile; explicit phone/tablet layouts use their own dimensions. Rock levels/remaining HP survive, with maximum HP reconstructed from saved mining power. Unavailable historic badge/reward dates stay unknown instead of being invented. Source holiday/audio/layout metadata and Easter hunt state are retained for their corresponding remaining modules.

During image validation, 16 existing item files were found to contain failed-download responses: four ordinary picks and twelve seasonal images. Original source-atlas textures replace those broken files; transparent padding/rotations are retained. Twelve lossless WebP variants keep imported seasonal icons compatible with CE's image-path migration. Original failed files and frame provenance are in the QA folder. No generated artwork or item reroll is involved.

Verification: 72 CJS suites and 68 parses (65 client/3 inline). New tests cover codecs, exact rolls, protected/unknown items, nickname zero sentinel, tiers/positions/planets, stacks, source history, source cycle, Altar mapping, repeated imports, invalid values, review cancellation and four atomic-write failure points. All 216 catalog images decode; no browser errors. Native navigation twice returned `Preview automation navigate timed out after 15000ms.` before the documented fallback. No physical controller certification or live cloud calls.
